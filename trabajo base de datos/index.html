¿Qué es Redis?

Redis es una base de datos NoSQL que trabaja principalmente en memoria RAM, lo que la convierte en una de las bases de datos más rápidas del mundo.

A diferencia de MySQL o PostgreSQL, Redis no trabaja con tablas clásicas, sino con estructuras de datos avanzadas como:

  • Strings (texto o valores simples)
  • Hashes (como fichas de usuarios)
  • Lists (listas o colas)
  • Sets (grupos sin repetir)
  • Sorted Sets (rankings ordenados)

Redis se utiliza mucho en videojuegos online, chats, redes sociales, sesiones de usuario, caché y sistemas en tiempo real.

Instalación de Redis

1. Instalación con Docker (recomendada)

Docker permite instalar Redis rápidamente sin configurar nada manualmente.

docker run -d --name redis -p 6379:6379 redis

2. Instalación en Ubuntu

sudo apt update sudo apt install redis-server

3. Comprobar que funciona

redis-cli ping
Resultado esperado: PONG

Si aparece PONG significa que Redis está funcionando correctamente.

CRUD Básico en Redis

CRUD significa:

  • Create → Crear datos
  • Read → Leer datos
  • Update → Actualizar datos
  • Delete → Eliminar datos

CREATE

Guardamos un usuario:

SET usuario:1 "Jorge"
OK

READ

Leemos el valor guardado:

GET usuario:1
"Jorge"

UPDATE

Cambiamos el nombre:

SET usuario:1 "Javier"
OK

DELETE

Borramos el usuario:

DEL usuario:1
(integer) 1

Estructuras de Datos en Redis

1. Hashes

Sirven para guardar varios campos dentro de una misma clave. Ideal para usuarios, productos o perfiles.

HSET user:1 nombre Jorge edad 20 ciudad Madrid
nombre Jorge
edad 20
ciudad Madrid

2. Lists

Se usan como colas de tareas o mensajes.

LPUSH tareas "Enviar correo"

3. Sorted Sets

Perfectos para rankings porque ordenan automáticamente por puntos.

ZADD ranking 2500 Jorge ZADD ranking 3200 Javier
1º Javier - 3200
2º Jorge - 2500

Consultas Más Importantes

Ver todos los datos de un usuario

HGETALL user:1
nombre Jorge
edad 20
ciudad Madrid

Ver ranking de mayor a menor

ZREVRANGE ranking 0 5 WITHSCORES
Javier 3200
Jorge 2500

Buscar usuarios guardados

KEYS user:*
user:1
user:2

Eliminar un usuario

DEL user:2
(integer) 1
